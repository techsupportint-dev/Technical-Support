# Finish deploy (app.js)

Most portal files are on `main`. Upload the full application script:

1. Open https://github.com/techsupportint-dev/Technical-Support
2. Click **Add file → Upload files**
3. Upload from your Drive folder `tech_support_portal/GITHUB_UPLOAD/`:
   - `app.js` (required)
   - Optionally replace `styles.css` with the full non-minified version
4. Commit to `main`

## Enable GitHub Pages (team URL)

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: **main** / folder: **/ (root)**
4. Save
