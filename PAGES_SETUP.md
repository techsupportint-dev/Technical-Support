# Fix: GitHub Pages 404

Your code is on `main` (including `index.html` and `app.js`).  
The 404 means **Pages is not published yet** — not a missing file.

## Fix (about 1 minute)

1. Open: https://github.com/techsupportint-dev/Technical-Support/settings/pages
2. Under **Build and deployment**:
   - **Source:** choose **GitHub Actions**  
     *(or* **Deploy from a branch** → Branch **main** / folder **/ (root)** *)*
3. Click **Save**
4. Open **Actions** tab: https://github.com/techsupportint-dev/Technical-Support/actions  
   - If using GitHub Actions, run **Deploy GitHub Pages** (or push any small commit)
5. Wait 1–2 minutes

## If it still 404s

- Confirm the repo is **public** (Settings → General), or your plan allows private Pages
- Confirm `index.html` is at the **root** of `main` (it is)
- Hard-refresh the browser or try an incognito window
